1. 概要                                               *refsearch-overview*

refsearch.nvim は、カーソル下の語でジャパンナレッジLib
(https://japanknowledge.com/lib/) を検索する Neovim プラグインです。

日本語の語は bunsetsu.nvim で辞書形に正規化してから検索します
(例: 「走っ」→「走る」)。検索は専用プロファイルのバックグラウンド Chrome
(Puppeteer) で実行するため、メインのブラウザには一切触れません。

所属機関の OpenAthens 経由でのアクセスを前提とします (大学等で
ジャパンナレッジLib を契約している方向け)。

================================================================================
2. インストール                                       *refsearch-install*

lazy.nvim: >lua
    {
        "kasi-x/refsearch.nvim",
        dependencies = { "kasi-x/bunsetsu.nvim" },
    }
<

puppeteer-core はグローバルインストール、またはプラグインディレクトリでの
ローカルインストール (`npm install`) が利用できます。

================================================================================
3. 設定                                                 *refsearch-config*

設定は vim.g.refsearch_configuration にテーブルで渡します。

default_source   既定の検索ソース名。省略値: "japanknowledge"
history_file     検索履歴キャッシュの保存先。
                 省略値: "~/.local/share/refsearch/history.json"
sources          ソースごとの設定テーブル。japanknowledge ソースでは
                 次のキーが使える:
                   redirector : OpenAthens リダイレクタ URL (必須)
                   proxy      : OpenAthens proxy のベース URL (必須)
                   script     : 検索スクリプトのパス
                   node       : node 実行ファイル
                   headless   : true でヘッドレス Chrome

設定例: >lua
    vim.g.refsearch_configuration = {
        default_source = "japanknowledge",
        sources = {
            japanknowledge = {
                redirector = "https://go.openathens.net/redirector/<your-domain>",
                proxy = "https://<resource>.proxy.openathens.net",
            },
        },
    }
<

================================================================================
3.1 ソースを追加する                               *refsearch-add-source*

`lua/refsearch/sources/<name>.lua` にテーブルを返すモジュールを置くと
(自プラグインの runtimepath でも可)、ソースとして使えるようになる。

必須フィールド:
    search(query, on_result)
        非同期で検索し on_result に結果を渡す。
        { status = "ok", results = { { title, dict, snippet, url } },
          exact = { ... }, total = n } の形式。

任意フィールド:
    fetch(item, on_done)  項目の全文を on_done(text) で返す。
    open(item)            項目をブラウザで開く。
    init(opts)            セッション初期化 (:RefSearchInit から呼ばれる)。

================================================================================
4. 使い方                                               *refsearch-usage*

コマンド:
    :RefSearch [語]     語を検索。省略時はカーソル下の語 (辞書形化)。
    :RefSearchInit      バックグラウンド Chrome を起動してセッション確立。
    :RefSearchInit!     可視ウィンドウで Chrome を起動 (手動ログイン用)。

Lua API:
    require("refsearch").command({ "語" })   コマンド本体。
    require("refsearch").search_cursor()     カーソル下の語を検索。
    require("refsearch").init({ visible })   セッション初期化。

検索結果は画面下部のパネルに表示され、索引ウィンドウでは以下のキーが
使えます:
    n / e     次 / 前の項目
    <CR>      カーソル行の項目をブラウザ (常駐 Chrome のタブ) で開く
    q         閉じる

検索結果と意味全文はローカルにキャッシュされ、同じ語の再検索は
ネットワークアクセスなしで表示されます。

================================================================================
5. 注意                                                 *refsearch-notice*

ジャパンナレッジLib は有料の契約データベースです。契約している機関の
アカウントでのみ使用してください。所属機関やジャパンナレッジの利用規約が
自動アクセスを禁止している場合は使用しないでください。
